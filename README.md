# مؤشر البورصة المصرية

تطبيق ويب لمتابعة **كل أسهم البورصة المصرية** (٢٢٩ سهماً): الأسعار، المؤشرات الفنية، وحالة الجلسة.
يُثبَّت على الشاشة الرئيسية ويعمل كتطبيق مستقل.

## المميزات

- **السوق كامل — ٢٢٩ سهم** بطلب واحد، مش سهم بسهم
- بحث فوري بالرمز أو الاسم العربي أو الإنجليزي (يتعامل مع اختلاف الهمزات والتاء المربوطة)
- ترتيب حسب الأعلى صعوداً / هبوطاً / حجماً / الاسم
- حالة السوق لحظياً (مفتوح / لم يفتح / أُغلق / إجازة) مع العد التنازلي
- تفاصيل كل سهم: مؤشر القوة النسبية، المتوسطات المتحركة، الدعم والمقاومة، السيولة، نطاق ٥٢ أسبوعاً
- رسم بياني لمئة وعشرين جلسة مع متوسطي عشرين وخمسين (يُحمَّل عند فتح السهم)
- تنبيهات عند اختراق مقاومة أو كسر دعم أو تشبع أو أعلى/أدنى سعر سنوي
- يعمل بدون اتصال (آخر نسخة محفوظة)

## مصدر البيانات

- **مباشر (TradingView)** — السعر اللحظي والمؤشرات الفنية لكل السوق في طلب واحد.
  الطلب يُرسل بـ `Content-Type: text/plain` عشان يفضل طلباً بسيطاً من غير
  preflight — ودي الطريقة الوحيدة اللي بتشتغل من المتصفح.
- **وسيط كلاودفلير** — تاريخ الجلسات لرسم الشارت ومستويات الدعم والمقاومة،
  ويُطلب لكل سهم على حدة عند فتح تفاصيله فقط.

### مهم: الوسيط الحالي معطّل

الوسيط المنشور على `egx-data.tahamahm3.workers.dev` **لا يرسل ترويسة
`Access-Control-Allow-Origin`**، لذلك كل متصفح يحجب ردوده. تم التأكد باختبار
٢٣ رمزاً — ولا واحد رجّع الترويسة.

التطبيق يتعامل مع ده تلقائياً: بيعرض الأسعار والمؤشرات من مباشر، وبيوضّح إن
الرسم البياني غير متاح. **لتفعيل الرسوم البيانية** انشر `worker.js`
(غلاف بيضيف الترويسة للوسيط الأصلي من غير ما يلمس منطقه):

```bash
export CLOUDFLARE_API_TOKEN=...   # صلاحية: Account → Workers Scripts → Edit
bash deploy-worker.sh
```

بعد النشر غيّر في `index.html`:

```js
const WORKER = 'https://egx-cors.tahamahm3.workers.dev';
```

## التشغيل محلياً

```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`

> خدمة العمل والتثبيت يحتاجان اتصالاً آمناً، وهو متوفر تلقائياً على صفحات جيت هب.

## قائمة الأسهم

القائمة كاملة في المصفوفة `DEFAULT` داخل `index.html` (٢٢٩ رمزاً)،
والأسماء العربية في `NAMES`.

**٤ رموز بلا بيانات:** `NAPR` `ALRA` `AIHC` `FCMD` — أوراق قليلة التداول
وغير مغطاة في المصدر. بتظهر في القائمة بعلامة «بلا بيانات» بدل ما تختفي.

> `ESRS` (حديد عز) مش في القائمة — الشركة اتشطبت من البورصة في مارس ٢٠٢٥
> وبقت بتتداول خارج المقصورة، ومفيش مصدر بيرجّع لها بيانات.

## بنية الملفات

```
index.html            التطبيق كامل (بلا تبعيات)
sw.js                 خدمة العمل — تخزين مؤقت للملفات، وشبكة أولاً للبيانات
manifest.webmanifest  بيانات التثبيت على الشاشة الرئيسية
icons/                أيقونات التطبيق
worker.js             غلاف CORS للوسيط (يُنشر على كلاودفلير)
deploy-worker.sh      نشر الغلاف + اختبار الترويسة
```
