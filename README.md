# مؤشر البورصة المصرية

تطبيق ويب لمتابعة أسهم البورصة المصرية: الأسعار، المؤشرات الفنية، وحالة الجلسة.
يُثبَّت على الشاشة الرئيسية ويعمل كتطبيق مستقل.

## المميزات

- حالة السوق لحظياً (مفتوح / لم يفتح / أُغلق / إجازة) مع العد التنازلي
- قائمة متابعة بالأسعار ونسب التغير ورسم مصغّر لآخر ثلاثين جلسة
- تفاصيل كل سهم: رسم بياني لمئة وعشرين جلسة مع متوسطي عشرين وخمسين
- مؤشرات: مؤشر القوة النسبية، المتوسطات المتحركة، الدعم والمقاومة، السيولة، نطاق ٥٢ أسبوعاً
- تنبيهات داخل التطبيق عند اختراق مقاومة أو كسر دعم أو تشبع أو أعلى/أدنى سعر سنوي
- يعمل بدون اتصال (آخر نسخة محفوظة)

## مصدر البيانات

- **مباشر (TradingView)** — السعر اللحظي والمؤشرات الفنية (RSI والمتوسطات والحجم).
  هذا المصدر يرسل ترويسة CORS فيعمل من المتصفح مباشرة ومن غير أي وسيط.
- **وسيط كلاودفلير** — تاريخ الجلسات لرسم الشارت ومستويات الدعم والمقاومة.
  عنوانه مضبوط داخل `index.html` في المتغير `WORKER`.

### مهم: الوسيط الحالي معطّل

الوسيط المنشور على `egx-data.tahamahm3.workers.dev` **لا يرسل ترويسة
`Access-Control-Allow-Origin`**، لذلك كل متصفح يحجب ردوده. النتيجة: التطبيق
كان يعرض «0 من 12 سهم» ولا يفتح الشارت إطلاقاً.

تم التأكد باختبار ٢٣ رمزاً — ولا واحد رجّع الترويسة. التطبيق الآن يتعامل مع
الوضع ده تلقائياً: بيعرض الأسعار والمؤشرات من مباشر، وبيوضّح إن الرسم البياني
محتاج الوسيط.

**لتفعيل الرسوم البيانية** انشر `worker.js` (غلاف بيضيف الترويسة للوسيط الأصلي):

```bash
export CLOUDFLARE_API_TOKEN=...   # صلاحية: Account → Workers Scripts → Edit
bash deploy-worker.sh
```

بعد النشر غيّر في `index.html`:

```js
const WORKER = 'https://egx-cors.tahamahm3.workers.dev';
```

## التشغيل محلياً

```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`

> خدمة العمل والتثبيت يحتاجان اتصالاً آمناً، وهو متوفر تلقائياً على صفحات جيت هب.

## تعديل قائمة الأسهم

في `index.html` عدّل المصفوفة `DEFAULT` وأضف الأسماء العربية في `NAMES`.

رموز متاحة ومختبرة: `COMI HRHO TMGH SWDY ETEL ABUK EFIH FWRY IRON MASR ORAS SKPC
PHDC JUFO MFPC CIEB AMOC ISPH EAST SUGR ORWE MTIE CANA`

> `ESRS` (حديد عز) اتشالت — الشركة اتشطبت من البورصة في مارس ٢٠٢٥ وبقت
> بتتداول خارج المقصورة، ومفيش مصدر بيرجّع لها بيانات. البديل المتاح: `IRON`.

## بنية الملفات

```
index.html            التطبيق كامل (بلا تبعيات)
sw.js                 خدمة العمل — تخزين مؤقت للملفات، وشبكة أولاً للبيانات
manifest.webmanifest  بيانات التثبيت على الشاشة الرئيسية
icons/                أيقونات التطبيق
worker.js             غلاف CORS للوسيط (يُنشر على كلاودفلير)
deploy-worker.sh      نشر الغلاف + اختبار الترويسة
```
